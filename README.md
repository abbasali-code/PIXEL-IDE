## 🇮🇷 فارسی

### دربارهٔ پروژه

**Pixel IDE** یک محیط کدنویسی مدرن با تمرکز بر سادگی، خلاقیت و تجربهٔ کاربری تمیز است.

این پروژه با هدف ایجاد فضایی ساده و جذاب برای کدنویسی و آزمایش ایده‌های جدید توسعه پیدا می‌کند.

### ✨ فلسفهٔ پروژه

- **سادگی** — تجربه‌ای روشن، قابل‌فهم و بدون پیچیدگی‌های غیرضروری.
- **خلاقیت** — فراهم‌کردن فضایی برای آزمایش و ایده‌پردازی.
- **توسعهٔ مستمر** — رشد و بهبود پروژه در طول زمان.
- **جامعهٔ توسعه‌دهندگان** — استقبال از بازخوردها و همکاری‌های سازنده.

### 🚀 وضعیت پروژه

Pixel IDE پروژه‌ای در حال توسعه است. طراحی، مسیر و قابلیت‌های آن ممکن است با پیشرفت توسعه تغییر کنند.

### 📜 مجوز

Pixel IDE تحت مجوز **MIT** منتشر می‌شود.

استفاده، کپی‌کردن، تغییر، انتشار و توزیع پروژه، از جمله استفادهٔ تجاری، مطابق با شرایط این مجوز مجاز است.

برای اطلاعات بیشتر، فایل [LICENSE](LICENSE) را مطالعه کنید.

## 🇸🇦 العربية

### حول المشروع

**Pixel IDE** هي بيئة حديثة لكتابة وتطوير الأكواد، تركّز على البساطة والإبداع وتوفير تجربة استخدام واضحة ومريحة.

يهدف المشروع إلى توفير مساحة مناسبة لكتابة الأكواد وتجربة الأفكار الجديدة، مع الاستمرار في التطوير والتحسين.

### ✨ فلسفة المشروع

- **البساطة** — تجربة واضحة وسهلة الاستخدام.
- **الإبداع** — تشجيع التجربة واستكشاف الأفكار الجديدة.
- **التطوير المستمر** — تحسين المشروع وتوسيعه بمرور الوقت.
- **المجتمع** — الترحيب بالملاحظات والتعاون البنّاء.

### 🚀 حالة المشروع

Pixel IDE مشروع قيد التطوير المستمر. وقد يتغير تصميمه واتجاهه وميزاته مع تقدم عملية التطوير.

### 📜 الترخيص
